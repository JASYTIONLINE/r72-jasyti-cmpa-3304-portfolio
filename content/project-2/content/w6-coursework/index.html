CMPA 3304 Week 6

Site Architecture and Navigation

This week marks a key conceptual shift: learning to build multi-page websites where several connected pages work together as a cohesive whole. The courseworkfocuses on the two fundamental concepts: site architecture (how pages are organized and linked together) and navigation systems (how users move between pages).

The coursework walks through the fundamentals of site architecture, illustrating how to organize files, link pages with proper relative paths, and use a shared stylesheet across the entire site. It also demonstrates how to create clean, consistent navigation using semantic HTML and Flexbox. The exercise brings it all together by adding additional pages and connecting them into one unified structure.
