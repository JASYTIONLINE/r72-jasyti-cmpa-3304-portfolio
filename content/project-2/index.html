Project 02 — Main Features

This professional portfolio site demonstrates every competency outlined in the Project 02 checklist and rubric: semantic structure, responsive design, content depth, accessibility, and professional documentation.

Semantic Structure & Navigation

  • Every page uses semantic regions (header, hero, aside, main, footer) to organize content logically.
  • Global nav and sidebar mirror the complete assignment/project hierarchy so graders can reach every artifact in two clicks.
  • Hero headlines and summaries frame each page’s purpose, satisfying the rubric’s content clarity requirement.

Visual Design & Responsive Layout

  • The shared stylesheet establishes a consistent typography scale, color palette, and spacing system.
  • Flexbox layouts keep the sidebar fixed while the main column remains fluid, and breakpoints ensure the layout collapses cleanly on tablets and phones.
  • Cards, dividers, and callouts highlight key deliverables, addressing the rubric’s visual hierarchy and polish criteria.

Accessibility, Interaction & Performance

  • Descriptive link labels, ordered headings, and semantic landmarks improve screen‑reader navigation.
  • Interactive elements (links, cards) maintain adequate color contrast and large hit targets to satisfy usability checks.
  • Lightweight assets and GitHub Pages hosting provide fast load times, exceeding the performance expectations in the rubric.

Professionalism & Documentation

  • Inline comments explain layout decisions, demonstrating intentional design thinking.
  • Version control is transparent through the linked GitHub repository, satisfying the process/documentation checklist item.
  • The project narrative connects skills learned across the course to a cohesive professional deliverable, earning full marks for reflection and presentation.
